# Examples

Copy-paste starters. One command each.

## What this is
The public start-here repo for Meshtool: copy-paste starters, one command each, so a stranger can try a seat without reading the whole estate first.

## Start with the real pieces, already public
- Meshtool SDK — TypeScript SDK and CLI for the MeshTool API: https://github.com/Meshtool/meshtool-sdk
- Meshtool Skills — public skill packs for the Meshtool estate: https://github.com/Meshtool/meshtool-skills
- MeshMarket MCP — connect any MCP client to the Meshtool platform and MeshMarket exchange: https://github.com/Meshtool/meshmarket-mcp
- Market — the live front door: https://market.meshtool.ai
- Runtime — the gatekeeper for your agents: https://runtime.meshtool.ai

## What it can and can't do
- It can: give a working starter, in one command, with a receipt for what it did.
- It can't: run outside its grants, use a key it was not given, or hide what it did.
- Limits are listed here as the starter rules land, not before.
