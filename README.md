# Examples

Copy-paste starters. One command each.

## What this is
The public start-here repo for Meshtool: copy-paste starters, one command each, so a stranger can try a seat without reading the whole estate first.

## What it can and can't do
- It can: give a working starter, in one command, with a receipt for what it did.
- It can't: run outside its grants, use a key it was not given, or hide what it did.
- Limits are listed here as the starter rules land, not before.
